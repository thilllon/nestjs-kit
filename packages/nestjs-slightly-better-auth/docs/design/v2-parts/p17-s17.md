## 17. Open questions and residual risks

### 17.1 Open questions for the user (genuine product trade-offs, each with a recommendation)

The design already applies every recommendation below, so answering "as recommended" changes nothing. Q1–Q12 come from the v1 merge. Q13–Q20 are the user decisions the round-1 reviewers proposed, de-duplicated:

- **Q13–Q17** are product trade-offs the lead did not want to settle alone. Each names the reviewer who raised it. **Q15 is the one place where the design's default differs from that reviewer's recommendation.**
- **Q18–Q20** were decided by the lead in v2 (D3 delegates naming, ADR-40 sets the fail-closed stance, and an app has one HTTP adapter). They are listed so that the user can overrule them before 1.0.
