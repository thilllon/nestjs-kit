### 6.7 Write-back rules common to every platform

| Concern                                                                          | Rule                                                                                                                                                                                                                                                                                                                                               | Evidence                                                                                                             |
| -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Multiple `Set-Cookie`                                                            | read via `getSetCookie()`, append each (H7)                                                                                                                                                                                                                                                                                                        | EXP-B:E4 `["a","b"]` on both platforms                                                                               |
| Streaming                                                                        | pass `response.body` through with backpressure                                                                                                                                                                                                                                                                                                     | better-auth returns streamed and HTML bodies (`BA/api/dispatch.ts:421-424`)                                          |
| HEAD                                                                             | status and headers, no body                                                                                                                                                                                                                                                                                                                        | better-auth answers HEAD with 404; the Fastify HEAD bug is avoided                                                   |
| Redirects                                                                        | verbatim 3xx + `Location` + cookies                                                                                                                                                                                                                                                                                                                | `ctx.redirect` is an `APIError('FOUND')` with a `location` header (R:ba-core §3.6, better-call `context.ts:309-312`) |
| Arbitrary content types                                                          | never re-serialize                                                                                                                                                                                                                                                                                                                                 | oauth-provider, SSO and error pages return raw Responses (R:ba-core §3.6)                                            |
| Host headers                                                                     | merge, don't clobber (`vary` union, `set-cookie` append)                                                                                                                                                                                                                                                                                           | CORS survives (EXP-B:E4, EXP-A:`exp-e2e`, EXP-C4/C6)                                                                 |
| The library's own Responses (413 `PAYLOAD_TOO_LARGE`, 400 `INVALID_REQUEST_URL`) | built by core as Web `Response`s and written through the same path, so they are byte-identical across platforms and carry host CORS headers (H4) `[R1:NEST-r1-04]`                                                                                                                                                                                 | EXP-B:E1/E4; LEAD-EXP-2                                                                                              |
| Failures                                                                         | never answered with a platform's default error body. A rejected `handle()` reaches the host error pipeline at request time: Express `next(err)`; Fastify's child error handler, which delegates to the root's current handler (H8, §6.4.2). With `onAPIError.throw` the original `APIError` travels the same way (H13) `[R1:NEST-r1-04, BA-r1-09]` | LEAD-EXP-2; LEAD-V25                                                                                                 |
| Nest interceptors, pipes and serializers                                         | never run on auth routes. Exception filters see auth routes only for those failures                                                                                                                                                                                                                                                                | better-auth principles P1/P2 (§0.2)                                                                                  |
