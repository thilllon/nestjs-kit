# Historical adapter reference

These files were carried over from the standalone repository's `legacy/` directory. They originate from `@thallesp/nestjs-better-auth` v2.4.0 and retain the [MIT copyright notice for Thalles Passos](LICENSE).

This is reference material for the rewrite, not a supported adapter. It is outside the active `src/` tree, is not built, tested or shipped in package archives, and its dependencies are intentionally not installed. Do not copy its option mutation, Nest internal imports or injection wrappers into new implementation without reviewing the current design and repository conventions.

Files remain available for comparison and research. Formatting follows the monorepo rules; historical test helpers were moved from `tests/shared/` to `tests/fixtures/` with their imports updated. For active development, start at the [package README](../README.md).

Original license source: [ThallesP/nestjs-better-auth v2.4.0](https://github.com/ThallesP/nestjs-better-auth/blob/v2.4.0/LICENSE).
