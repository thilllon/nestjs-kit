"nestjs-slightly-better-auth": patch
---

Deliver infrastructure errors that a principal source or policy classifies itself, such as API-key outage-probe failures, with the request's cookie, authorization and declared credential values redacted from the cause, and keep the original cause reachable through `getRawCause()` when `errors.exposeRawCause` is set. The Express and Fastify cookie sinks and auth-route responses skip a `Set-Cookie` line identical to the latest line already set for the same cookie, so a call's cookies that both the bridge and a source forward arrive once. The WebSocket README example lists `bearer()` before `nestjs()`.
