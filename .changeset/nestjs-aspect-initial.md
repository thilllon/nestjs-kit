Add the `nestjs-aspect` package for Spring-style aspect-oriented programming in NestJS. `AspectModule.forRoot()` and `forRootAsync()` weave aspects into the classes the Nest container registers (providers, controllers, enhancers and middleware of every scope) before the router binds route handlers and before the first lifecycle hook; middleware passed only to `consumer.apply()` and the instances of singleton factory and value providers are woven when the application initializes. The module comes with the `returnValueAdapters`, `report`, `strict` and `exclude` options, bootstrap validation and a weaving report. The package provides typed annotations (`createAnnotation`), the `P` pointcut designators with `and`, `or` and `not` composition, the `@Aspect`, `@Before`, `@After`, `@AfterReturning`, `@AfterThrowing` and `@Around` decorators with advice signatures checked against their pointcut, the `@Advisor` decorator with the `PointcutAdvisor` and `MethodInterceptor` interfaces, the `AdviceAdapter` and `ReturnValueAdapter` extension interfaces with the built-in `promiseAdapter`, and the `AspectConfigurationError`, `AspectUsageError` and `AspectNotReadyError` error classes.
